How to Use

Once you visit the live application, you can interact with the chatbot using natural language commands such as:

  • "Add a task to buy groceries"
  • "Show me all my tasks"
  • "What's pending?"
  • "Mark task 3 as complete"
  • "Delete the meeting task"
  • "Change task 1 to 'Call mom tonight'"
